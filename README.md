# TBQ Amal GoDaddy Website Backup

This repository contains the extracted WordPress website files from the GoDaddy backup for `tbqamal.org`.

The live WordPress configuration and database dump are kept out of Git because they can contain credentials, salts, user data, donation/order records, and other private data.

Local migration files:

- `godaddy-backup/wp-config.php`
- `godaddy-backup/.wp-config.php.replaced.bak`
- `godaddy-backup/mwp_db/`
- `godaddy-backup/wp-content/uploads/2026/02/Video-Project-1.mp4`
